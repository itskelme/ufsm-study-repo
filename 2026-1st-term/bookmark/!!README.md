🚀 Sobre o Projeto

Este projeto consiste na entrega da interface Frontend da aplicação. A interface foi desenvolvida de forma limpa e direta utilizando HTML, CSS e JavaScript.



Para garantir uma experiência funcional e persistente, os dados inseridos na plataforma são processados e salvos de forma integrada por meio do Backend.



🛠️ Tecnologias e Ferramentas Utilizadas

O projeto foi refinado e desenvolvido com o auxílio das seguintes tecnologias:



Zed.dev: Editor de código de alta performance utilizado para a escrita do projeto.



Claude AI: Utilizado como assistente auxiliar no refinamento do código e da lógica.



Firebase: Plataforma utilizada no ecossistema do backend para a gestão de dados.



💻 Como Executar o Projeto

Como o frontend está sendo enviado de forma direta, não é necessário instalar dependências complexas. Basta seguir os passos abaixo:



Extraia o arquivo compactado (.zip) enviado em uma pasta de sua preferência.



Localize o arquivo chamado index.html na raiz do projeto.



Abra o index.html diretamente em qualquer navegador de sua escolha (Chrome, Edge, Firefox, etc.).



Faça o Login na tela inicial.



Pronto! Agora você já pode navegar e utilizar o site normalmente.



⚠️ Importante (Nota de Navegação): > Ao clicar no botão Sair e retornar para a tela de login, por favor, atualize a página (F5) do navegador para garantir que todas as sessões sejam reiniciadas corretamente e o sistema funcione sem inconsistências.
